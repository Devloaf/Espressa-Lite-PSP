Espressa Lite for PSP a0.3 by c4thead

| Espressa Lite for PSP Alpha 0.3 (build 128) Rostov Edition
| [2026.05.07]
----------------------------------------------
	- Fully recreated color palette from a little sliding square into a panel that slides from the bottom of the screen (Palette now has its own Class file). Now palette displays color names (colors now are loaded from the external config file, you can change it to the way you want if you want to)
	- Added +3 more colors (now with total of 18). Changed base colors
	- Added an ability to change cursor's speed (by pressing [ X ] button)
	- Added an ability to move cursor by 1 pixel (change cursor's speed to the max to switch)
	- Added an ability to draw squares (by pressing [ [] ] button)
	- Added a draw area before cursor (guide drawing area) to make drawing process more comfortable
	- Now when you erase or draw squares/circles, the cursor's icon change
	- Now you can change size of the brush from 1 up to 50 (basically, with no limits and no pre-drawn brushes)
	
	- Misc: DEBUG menu now features the build number of the app ("b128 FPS: 60")
	- Misc: Cleaned up some parts of the code and moved out of the Editor.lua like color selector and drawing process of the cursor
	- Misc: Changed the way cursor behaves with the borders (movement of a cursor has been rewritten entirely)
	- Misc: New functions - Bool(), getFreeMem(), drawFilledCircle(), drawCircleOutline(), drawFilledSquare(), drawSquareOutline()
	- Special Edition: This is a Rostov Edition. Such a great city, it was a pleasure to spend my time in here with my friends, i appreciated that time of my being in here. The title and ICON0 have been changed to RE

| [2026.03.30]
----------------------------------------------
	- Added a sliding animation to the Palette (it's a little buggy and might get stuck), it also teleports to the other edge of the screen for the better visibility. Also added a gray backcolor to the palette to distinguish it better from your canvas
	- Changed deep purple color to deep blue

	- Screenshot/save/snapshot is now being taken as a permanent date written in Funcations.lua as 20260330_HHMMSS.png (the time is still custom to your current system time). You can now take a screenshot from the menu
	- Removed some unnecessary old garbage from the app's files
	- The Cursor code is now a separate class file (from now on i'll be moving everything to classes for better and cleaner code)
